# Studio Atlas · app

Interfaz web de Studio Atlas, instalable en móvil y escritorio. Se publica con GitHub Pages en https://morphovision.github.io/studio-atlas-app/

No contiene datos ni claves secretas: los datos viven en Supabase, protegidos por inicio de sesión y reglas de acceso por usuario. El motor está en el repositorio privado `studio-atlas`.
